# Bugs playlist creator

Bugs Music에서 플레이리스트를 만들고, MBC 공식 배철수의 음악캠프 선곡을 하루별 또는 기간별 플레이리스트로 가져오는 Node.js + Playwright 예제입니다.

## 준비

- Node.js 20 이상
- Bugs 계정

```sh
npm install
npx playwright install chromium
```

## Bugs 로그인

처음 실행하면 Chromium 창이 열립니다. Bugs에 직접 로그인하면 이후 작업을 이어갑니다. 브라우저 프로필은 프로젝트 폴더의 `.bugs-profile/`에 저장되어 다음 실행에 재사용됩니다. 이 폴더는 Git에서 제외됩니다.

## 배철수 음악캠프 일별 플레이리스트

특정 방송일의 플레이리스트 하나를 만듭니다.

```sh
npm start -- --date 2026-11-22
```

날짜 범위의 방송을 각각 별도 플레이리스트로 만듭니다.

```sh
npm start -- --from 2026-11-20 --to 2026-11-22
```

기간 내 모든 방송 선곡을 한 플레이리스트에 모으려면 제목을 지정합니다. 방송일 순서로 곡을 추가합니다.

```sh
npm start -- --from 2026-11-20 --to 2026-11-22 --playlist-title "배캠 11월 모음"
```

미리보기는 동일한 명령에 `--dry-run`을 추가합니다. 기간 옵션은 최대 31일이며, 같은 이름의 플레이리스트가 이미 있으면 건너뜁니다.

실제 Bugs 변경 없이 MBC 선곡과 트랙 수를 확인하려면 `--dry-run`을 추가합니다.

```sh
npm start -- --date 2026-11-22 --dry-run
```

플레이리스트 이름은 `배철수 음악캠프 YYYY-MM-DD` 형식입니다. 같은 이름의 플레이리스트가 이미 있으면 중복 추가를 피하기 위해 해당 날짜는 건너뜁니다. Bugs에서 정확한 곡을 찾지 못하면 건너뛰고 결과에 표시합니다. 같은 곡의 버전이 여러 개면 Bugs 검색 결과 중 제목과 아티스트가 일치하는 첫 번째 결과를 선택합니다.

곡 순서는 Bugs 계정의 ‘내 앨범에 곡 담기 위치’ 설정을 따릅니다. 방송 순서를 유지하려면 곡을 앨범의 아래쪽에 담도록 Bugs 설정을 확인하세요.

선곡 원본은 MBC 배철수 음악캠프의 공식 선곡표(RAMFM300)입니다. MBC 페이지의 이용 조건을 확인해 개인적인 용도로 사용하세요.

## 빈 플레이리스트만 만들기

기존 방식도 지원합니다.

```sh
npm start -- "출근길 음악"
```

실제 저장 없이 생성 화면만 확인하려면 `--dry-run`을 사용합니다.

```sh
npm start -- "출근길 음악" --dry-run
```

Bugs 웹사이트가 변경되면 UI 선택자 수정이 필요할 수 있습니다.

## 파일

- `bugs-playlist.mjs` — 플레이리스트 생성, MBC 선곡 수집, Bugs 곡 검색 및 추가
- `.gitignore` — 로그인 세션과 로컬 산출물 제외
- `package.json` — 실행 명령과 Playwright 의존성
